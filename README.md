# Moment theme: public images

Images the Moment Salla theme loads from outside the theme:

- `sections/`: the previews in Salla's «إضافة عنصر» picker, one per home section (800×400).
- `brand/`: the Moment logo, used in the support box at the top of the theme settings.

The theme code lives in a private repository. The previews are generated there; do not edit them by hand.
